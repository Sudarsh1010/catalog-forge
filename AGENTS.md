# catalog-forge

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues (github.com/Sudarsh1010/catalog-forge) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The default triage labels are used unchanged: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: a root `GLOSSARY-MAP.md` points at one `GLOSSARY.md` per context, with context-scoped `docs/adr/` alongside each. See `docs/agents/domain.md`.
